# JavaScript30 - TypeScript

30 proyectos prácticos para aprender y reforzar **TypeScript**, basados en el desafío [JavaScript30](https://javascript30.com/) de Wes Bos.

El objetivo de este repositorio es desarrollar proyectos pequeños y prácticos para familiarizarme con TypeScript, el DOM, eventos, manipulación de elementos HTML, APIs del navegador y otros conceptos fundamentales del desarrollo web.

## 🚀 Tecnologías

- TypeScript
- JavaScript
- HTML5
- CSS3
- Node.js
- npm

## 🎯 Objetivos

- Aprender TypeScript mediante proyectos prácticos.
- Familiarizarme con el tipado estático.
- Mejorar el manejo del DOM y las APIs del navegador.
- Practicar eventos y manipulación de elementos HTML.
- Comprender las diferencias entre JavaScript y TypeScript.
- Mejorar progresivamente la estructura y calidad del código.
- Prepararme para posteriormente trabajar con frameworks como React.

## 🛠️ Instalación

Clonar el repositorio:

```bash
git clone <URL_DEL_REPOSITORIO>
cd javascript30-typescript
```

Instalar las dependencias:

```bash
npm install
```

## 📌 Progreso

Este repositorio se irá actualizando a medida que complete los 30 desafíos.

La intención no es solamente completar los ejercicios, sino utilizar cada proyecto como una oportunidad para aprender y aplicar TypeScript de manera progresiva.
